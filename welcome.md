# Welcome to mado

Click any line and edit it **right here** in the preview. There is no second window.

> [!note] One file, one view
> This page is the editor. What you read is what you edit.

## Try it

- [x] Click a paragraph, heading, or list
- [ ] Change the words, then click away — it re-renders and saves
- [ ] Press Enter at the end of a line to keep writing
- [ ] Press Cmd+E if you ever want the raw markdown for the whole file

| Key | Action |
| --- | --- |
| Enter | New block |
| Esc | Done editing |
| Cmd+E | Raw file / back to preview |
| Cmd+S | Save now |
